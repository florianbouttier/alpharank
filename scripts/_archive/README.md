# Scripts archivés

Ce dossier conserve des commandes sans lecteur actif. Elles ne doivent pas être
utilisées pour un nouveau run. Chaque lot daté possède son inventaire, ses
hashes avant déplacement et son remplacement dans le registre
[`../../docs/architecture/script_archival_audit_v1.json`](../../docs/architecture/script_archival_audit_v1.json).

Les entrées maintenues sont documentées dans [`../README.md`](../README.md).
