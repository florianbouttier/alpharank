# Configurations de recherche

Chaque JSON fige une hypothèse ou un profil expérimental : univers, seuils,
allocation et paramètres de validation. Ces fichiers ne sont pas des réglages
de production implicites.

Pour promouvoir un profil, documenter le run dans un journal daté indexé par
`docs/research/boosting_signal_copy_model_catalog.md`, conserver son manifeste
et le rejouer sur le même snapshot que Legacy.
